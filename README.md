# Blue Wave Modular System

A responsive React and Vite website for Blue Wave Modular System, an office furniture solutions and workspace design company.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The production output is generated in `dist/` and can be deployed to any static host. Pushes to `main` automatically deploy to GitHub Pages through the included workflow.
